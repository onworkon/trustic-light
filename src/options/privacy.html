개인정보 처리방침

신뢰등 · 버전 0.3.0 · 2026년 9월 17일

1. 처리하는 정보와 목적

신뢰등은 사용자가 직접 요청한 웹 글의 표현과 근거를 분석합니다. 분석 버튼을 누르면 해당 페이지의 제목과 본문 최대 9,000자를 Anthropic API에 전송합니다. 분석 전 설정에서 본문 전송에 동의해야 합니다. 입력란, 편집 중인 영역, 숨겨진 요소는 본문 추출에서 제외하도록 설계되어 있습니다. 사이트 구조에 따라 본문에 표시된 개인정보가 포함될 수 있으므로 민감한 글을 분석하지 않도록 주의해 주세요.

2. 외부 전송

수신자는 Claude API를 제공하는 Anthropic입니다. 사용자가 등록한 API 키는 인증에 사용되며 제목과 본문은 분석 결과를 받는 데 사용됩니다. 연결 확인 시에는 키와 모델 조회 요청만 전송하고 본문은 전송하지 않습니다. 전체 페이지 주소, 쿠키, 비밀번호 입력값, 방문 기록은 전송하지 않습니다. API 통신에는 IP 주소 등 일반적인 네트워크 정보가 수반됩니다. 본문 안에 쓰인 주소나 개인정보는 텍스트의 일부로 전송될 수 있습니다.

전송 이후의 보관·삭제·처리는 이용자의 Anthropic 계정에 적용되는 계약 및 Anthropic 개인정보 처리방침을 따릅니다. 이 확장 프로그램에서 키나 결과를 삭제해도 Anthropic이 처리한 정보까지 삭제되는 것은 아닙니다.

3. 로컬 저장과 삭제

API 키, 전송 동의, 활성화 여부, 패널 방향과 신호등 위치를 Chrome 로컬 저장소에 저장합니다. Chrome 동기화 저장소는 사용하지 않습니다. API 키는 확장 프로그램의 신뢰된 실행 환경에서만 접근하도록 제한하지만, 로컬 저장소 자체가 암호화된 비밀 금고는 아닙니다. 분석 본문과 결과는 실행 중 메모리에서만 사용하며 영구 저장하지 않습니다. 페이지를 이동하거나 닫으면 해당 화면의 분석 결과가 사라집니다.

설정에서 API 키 삭제 후 저장하거나 동의를 해제할 수 있습니다. 확장 프로그램을 제거하면 해당 확장 프로그램의 로컬 데이터가 삭제됩니다. 개발자가 별도로 운영하는 수집 서버, 광고 추적기, 사용 통계 도구는 없습니다.

4. 이용 범위와 문의

정보는 사용자가 요청한 본문 분석과 연결 설정 기능에만 사용합니다. 개인정보를 판매하거나 광고 목적으로 사용하지 않습니다. 문의는 프로젝트 저장소의 Issues를 이용해 주세요. 문의에 API 키나 개인정보를 포함하지 마세요. 데이터 처리 방식이 변경되면 처리방침과 제품 안내를 갱신하고 필요한 동의를 다시 받습니다.

신뢰등의 AI 분석은 외부 사실 확인이나 정보의 진위 보증이 아닙니다.
