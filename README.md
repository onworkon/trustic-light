# 신뢰등 (TrustLight)

웹 글의 표현·출처·논거를 AI로 분석하고, 신호등과 문장별 설명으로 보여주는 Chrome 확장 프로그램입니다. 독자가 글의 근거와 편향을 살펴보며 읽도록 돕습니다.

## 주요 기능

- **신호등 분석**: 0~100 참고 점수와 양호·주의·경고 표시
- **문장별 설명**: 편향 유형과 분석 근거를 확인하고 해당 본문으로 이동
- **읽기 화면 설정**: 신호등 위치 이동, 좌우 패널 선택, 키보드 조작
- **직접 실행**: 본문 전송에 동의한 뒤 분석 버튼으로 시작하고 진행 중 취소

## 설치 및 사용

Node.js 22 이상, Chrome 120 이상이 필요합니다. 실제 분석에는 본인의 Anthropic API 키와 Claude Opus 5 접근 권한이 필요하며 API 사용 요금이 발생할 수 있습니다.

```sh
npm ci
npm run build
```

1. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드**하고 생성된 **`dist` 폴더**를 선택합니다.
3. 확장 아이콘을 눌러 설정에서 API 키를 입력하고 본문 전송에 동의한 뒤 저장합니다.
4. 읽을 웹페이지를 새로고침하고 신호등 → **이 글 분석하기**를 누릅니다.
5. 결과의 문장별 설명을 선택해 원문의 해당 위치를 확인합니다.

API 없이 화면만 확인하려면 빌드 후 `node scripts/preview.mjs`를 실행하고 <http://127.0.0.1:4173/article>을 엽니다. 이 미리보기는 고정된 모의 결과를 사용하며 실제 AI 분석이 아닙니다.

## 검증 및 제출 파일

| 명령                     | 결과                                                 |
| ------------------------ | ---------------------------------------------------- |
| `npm run check`          | 소스 파일 검사, 타입 검사, 테스트, 빌드, 포맷 검사   |
| `npm run package`        | 확장 프로그램 ZIP: `release/trustlight-0.3.0.zip`    |
| `npm run package:source` | 소스 코드 ZIP: `release/trustlight-source-0.3.0.zip` |

ZIP 생성 시 전체 검사를 수행하며 API 키와 로컬 전용 파일은 포함하지 않습니다. 자동 테스트는 모의 응답을 사용합니다. 실제 API 연결과 분석은 설치 후 본인의 키로 확인할 수 있습니다.

## 코드 구성

| 경로                 | 역할                                   |
| -------------------- | -------------------------------------- |
| `src/background/`    | API 통신, 요청 검증, 취소, 설정 저장   |
| `src/content/`       | 본문 추출, 신호등·결과 패널, 문장 강조 |
| `src/options/`       | 설정 화면과 개인정보 처리방침          |
| `src/shared/`        | 공통 타입과 메시지 처리                |
| `scripts/`, `tests/` | 빌드·패키징 도구와 자동 테스트         |

TypeScript와 브라우저 기본 API로 구현한 Manifest V3 확장 프로그램입니다.

## 데이터 처리와 분석 범위

사용자가 동의하고 분석을 요청할 때만 페이지 제목과 본문 최대 9,000자를 Anthropic에 전송합니다. API 키는 Chrome 로컬 저장소에 보관하며, 분석 본문과 결과는 영구 저장하지 않습니다. 자세한 내용은 [개인정보 처리방침](src/options/privacy.html)을 참고하세요.

점수는 글의 표현과 근거에 대한 AI의 참고 평가입니다. 외부 검색을 통한 사실 확인이나 진위 판정을 제공하지 않으며 결과가 틀릴 수 있습니다. 일반적인 텍스트 웹페이지를 대상으로 하며 Chrome 내부 페이지, 시크릿 모드, 이미지·영상 속 글은 분석 대상에 포함되지 않습니다.
