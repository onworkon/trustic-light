# 전체 검토와 리팩토링 기록

대상: 원래 폴더의 Manifest V3 0.2.10 배포물 전체. 변경 버전: 0.3.0.

## 주요 발견과 조치

| 중요도 | 기존 상태                                                                           | 조치                                                                      |
| ------ | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 치명적 | `private/bootstrap.json`에 평문 API 키가 포함되고 설치 후 자동 저장됨               | 로더 제거, 개인별 등록, 키 파일 배포 제외, 빌드 단계 키 패턴 검사         |
| 높음   | `chrome.storage.local`에 API 키와 일반 설정이 함께 있고 콘텐츠 스크립트도 접근 가능 | 신뢰된 확장 환경으로 접근 제한, 별도 키 저장, 메시지로는 보유 여부만 반환 |
| 높음   | 메시지 발신자의 탭·프레임·확장 ID와 설정 페이지 권한을 검증하지 않음                | 요청별 발신자 권한, 타입·길이·한도 검사                                   |
| 높음   | 본문 전송에 대한 명시적 제품 내 동의와 배포용 정책 자료 없음                        | 동의 기본 해제, 제목·본문·수신자·비용 안내, 정책 페이지·스토어 문구 작성  |
| 높음   | 취소가 화면 상태만 초기화하고 API 요청은 계속될 수 있음                             | 실제 네트워크 AbortSignal, 탭 닫힘·이동·설정 변경 시 중단                 |
| 중간   | 누락된 reliability를 0으로 보정하여 잘못된 경고를 만들 수 있음                      | 올바르지 않은 결과는 오류 처리, 점수 경계 검증                            |
| 중간   | AI 인용을 축소·보정해 본문과 느슨하게 연결                                          | 전송한 본문에 실제 존재하는 연속 인용만 표시                              |
| 중간   | 중복·동시 분석과 재시도로 비용이 증가할 가능성                                      | 비동기 처리 전 요청 슬롯 예약, 동시성·빈도 제한, 유료 자동 재시도 제거    |
| 중간   | 동적 import를 위해 UI·설정 번들을 전체 사이트에 웹 접근 가능 리소스로 공개          | 콘텐츠 코드를 단일 로컬 번들로 생성, 해당 선언 제거                       |
| 중간   | SDK·React·범용 CSS를 포함한 압축 번들만 있고 소스·빌드·테스트 없음                  | 책임별 TypeScript 모듈, 브라우저 기본 API, 고정된 개발 도구와 회귀 테스트 |

## 보존한 동작과 명시적 변경

신호등, 0~100 참고 점수, 3단계 표시, 10종 편향 분류, 최대 8개 인용, 상세 설명, 문장 위치 이동, 좌우 패널 방향, 신호등 위치 저장, API 연결 확인, 활성화 설정을 제공합니다. Claude Opus 5와 본문 9,000자 한도를 유지합니다.

첫 클릭은 분석 안내 패널을 열고, 명확히 표시된 분석 버튼이 외부 전송을 시작합니다. 상세 설명은 같은 결과 패널에 표시합니다. 숨은 더블클릭 기능 대신 명시적 조작을 제공하고, 위치 이동은 별도 손잡이와 키보드를 사용합니다. 본문 하이라이트는 원래 웹페이지 클릭을 가로채지 않으며, 결과 패널에서 인용을 선택해 이동합니다. 원본 레이아웃에 맞춰 반투명 신호등의 시각적 성격을 유지하면서 복잡한 애니메이션과 타이핑 효과를 단순화했습니다.

## 검증 범위와 제한

자동 테스트는 점수 경계, 잘못된 모델 응답, 허위 인용, 입력 한도, SSE 종료·오류, 응답 크기, HTTP 오류 은닉, 취소, 권한 경계, 저장소 마이그레이션, 민감 영역 제외, 인라인 DOM 인용, 동시 요청을 검증합니다. 빌드는 실제 허용 파일과 매니페스트 참조를 검사하고 비밀 키 패턴·동적 코드 실행 패턴을 차단합니다.

로컬 UI 미리보기는 가짜 Chrome 메시지와 고정된 분석 결과를 사용합니다. 실제 확장 격리 환경의 설치, 워커 휴면 후 복귀, Anthropic의 실서버 결과, 스토어 심사는 별도 확인이 필요합니다. 외부 API 키를 사용한 유료 호출은 자동 테스트에 포함하지 않습니다. 본문 추출은 일반적인 article/main DOM 기준이며 사이트별 읽기 순서, 가상 스크롤, 닫힌 Shadow DOM, iframe, Canvas 문서는 완전하게 지원하지 않습니다.

기존 `private/bootstrap.json`의 키는 재배포하지 않지만 이미 공유된 사본까지 회수할 수 없습니다. 원본 키의 폐기·재발급은 계정 소유자가 Anthropic 콘솔에서 완료해야 합니다.

## 이번 실행에서 확인한 내용

- TypeScript 엄격 검사와 Chrome 120 대상 빌드 통과.
- 회귀 테스트에서 동의 전 자동 전송 방지, SPA 이동 시 이전 결과 폐기, 설정 해제 시 취소, 모델 출력의 HTML 실행 방지를 포함해 검증.
- Chrome 로컬 UI 미리보기에서 설정 저장, 키 표시·삭제, 전송 동의, 패널 방향, 신호등 열기, 모의 분석 결과, 본문 강조 확인.
- 390 × 844 크기의 화면에서 패널이 화면 안에 배치되는지 확인. 브라우저 콘솔 오류 없음.
- 제출 ZIP에는 매니페스트·스크립트·스타일·설정/정책 HTML·아이콘만 포함. 원본 API 키·부트스트랩·개발 도구는 제외.
